# Code-drawn scene assets

These SVG assets are repo-native pixel-style illustrations used when a scene needs a precise mobile composition. They are intentionally kept separate from provided crops and generated raster masters.

| File                         | Usage                                                  |
| ---------------------------- | ------------------------------------------------------ |
| `kyungdong-bus-stop.svg`     | DAY 1 Kyungdong University urban bus-stop background   |
| `outreach-volunteers.svg`    | DAY 1 campus outreach and DAY 2 village outreach       |
| `international-students.svg` | DAY 1 international-student outreach counterpart group |

All three use crisp-edged vector geometry, contain no external fonts or linked resources, and can be loaded directly by Phaser.
